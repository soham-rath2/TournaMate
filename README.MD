# Presenting: the TournaMate project.

Imagine you and your friends want to compete, to finally see, who actually is the best at chess in the group. Well, TournaMate is the solution!

TournaMate is a web-based chess tournament manager for chess events with support for:
Team and Individual Tournaments, changing of the pairing system(Swiss System, Round Robbin) and much more!

You can demo the project here: [**Open TournaMate Preview**](https://soham-rath2.github.io/TournaMate/)

To clone and run it, you just:

```bash
git clone https://github.com/soham-rath2/TournaMate.git
```

Unzip the folder and run index.html!
