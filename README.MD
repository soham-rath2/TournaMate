# Presenting: the TournaMate project.

Imagine you and your friends want to compete, to finally see, who actually is the best at chess in the group. Well, TournaMate is the solution!

TournaMate is a web-based chess tournament manager for chess events with support for:
Team and Individual Tournaments, changing of the pairing system(Swiss System, Round Robbin) and much more!

You can demo the project here: [**Open TournaMate Preview**](https://soham-rath2.github.io/TournaMate/)

To clone and run it, you just:

```bash
git clone https://github.com/soham-rath2/TournaMate.git
```

Unzip the folder and run index.html!

# My journey

Last month, I and some friends of mine hosted a chess tournament in our school and noticed, that there are no good chess tournament managers, that look good, are easy to operate and free. So I decided to make this project to fix this problem.
There are still many features I would like to add, like being able to integrate Google Sheets and adding team player names.

I actually faced many problems in the making of this project, especially with Hackclub.
I started on Saturday of Prep Week 3, worked on the project for 3.5 hours and also bought many apples and dirt. But then on Monday morning I wake up and see, that the plants are rotting and even the watered plants can't be collected.
At the end I lost 3 apple seeds and about 3.5 hours of progress.

But still till now this journey has been great and I am very thankful of Hackclub for motivating me to make this project.
